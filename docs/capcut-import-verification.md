# 2단계: CapCut 편집 재료 가져오기 검증

1단계 커밋: `1172b6b`. 기존 코드와 테스트를 유지했다.
이번 단계는 pycapcut을 사용하지 않으며 CapCut 내부 파일을 읽거나 직접 수정하지 않는다.
사용자 기존 프로젝트 수정·삭제, 원본 파일 변경·삭제, 외부 업로드를 수행하지 않는다.

## 구현

- 인트로 / 5위\~1위 / 아웃트로, 제목과 순위, 프레임 기준 시작·종료 시간 구성 JSON
- PNG/JPG 검증, EXIF 방향 보정, 비율 유지한 1080×1920 PNG, 원본 복사본
- MP3 오디오 스트림과 길이 검사, 전체 디코딩 검사, 영상 길이와 비교
- 가사 검증과 UTF-8 SRT 저장; 각 자막 시작·종료 시간은 밀리초로 출력
- Pillow로 가사 합성한 프레임과 FFmpeg H.264/AAC 1080×1920·30fps 미리보기
- 상대 경로 패키지와 로컬 가져오기 안내서

구성 JSON은 다음 단계 화면 조작에 필요한 순서, 경로, 시작/종료 시간, 자막 정보를 제공한다.
패키지 생성과 앱 조작을 분리했다. 앱 조작 자동화는 아직 구현하지 않았다.
미리보기 제목/순위 타이틀을 별도로 합성하는 기능, 전환·줌 효과, 대규모 GUI는 이번 범위에 포함하지 않았다.

## 시험 입력

Python 3.12.15, Mac CapCut 5.9.1, 기존 Pillow/Pydantic/FFmpeg 환경.
3초 합성 PNG(720×1280 → 1080×1920), 440Hz MP3(3초), 두 개의 한글 가사.
인트로 0.4초 + 순위 각 0.4초 ×5 + 아웃트로 0.6초.
가사1 0.5\~1.5초, 가사2 1.5\~2.5초.
실제 Suno 파일은 제공되지 않아 사용하지 않았다.

## 실제 앱에서 관찰한 내용

UI로 새 프로젝트를 생성했다. 표시 이름은 `Shortsaker_Stage2_Import_Test`이며
앱이 지정한 새 폴더 이름은 `1009 (2)`이다. 이름의 누락 글자는 시험 조작 입력 결과다.
앱이 자체 저장한 파일은 프로그램으로 직접 수정하지 않았다.

| 항목 | 관찰 결과 |
|---|---|
| PNG 가져오기 | `prepared/01_장면.png`가 목록과 플레이어에 정상 표시됨 |
| MP3 가져오기 | `audio/음악.mp3`가 목록과 오디오 트랙에 추가됨 |
| SRT 가져오기 | 텍스트 → 로컬 자막으로 가져온 후 두 개의 자막 클립으로 생성됨 |
| 한글 개별 수정 | 첫 자막을 `수정 완료 한글 자막`으로 변경; 둘째 자막은 원문 유지 |
| 규격/길이 | 앱에서 9:16, 30fps 설정; 이미지와 MP3를 3초에서 잘라 새 시험 타임라인 구성 |
| 재생 | 재생 위치 진행, 이미지·첫 자막 표시와 오디오 레벨 변화를 관찰 |
| 내보내기 | 1080P/H.264/30fps 내보내기 창 확인, 공간 동기화 체크 해제; 최종 파일 출력 미완료 |

재생 중 오디오 레벨 확인은 실제 스피커 청취 검증과 다르다.
SRT 기본 글꼴·위치·크기는 CapCut에서 결정하며, 제작자가 후속 조정할 수 있다.
7개 장면을 앱에 전부 배치한 시험은 하지 않았다. 가져오기 경로 검증을 위해 동일 합성 이미지 한 장을 3초로 사용했다.

## 미해결 사항

MP4 형식 선택 중 컴퓨터 조작 도구가 `noWindowsAvailable`, `cgWindowNotFound` 오류를 반환했다.
앱 재연결을 시도했으나 창을 다시 얻지 못했다. 최종 MP4 출력, 출력물의 영상/오디오 검사,
저장 후 프로젝트 재열기는 완료되지 않았다. 사용자에게 창을 띄워 상태를 확인해 달라고 요청했다.
**전체 검증 성공으로 보고하지 않는다.** 가져오기와 한글 개별 수정은 실제 앱에서 확인한 부분 성공이다.

## 자동 테스트 및 미리보기 확인

기존 1단계 테스트 3개를 포함한 전체 테스트 11개가 통과했다.
가사 충돌·범위·빈 텍스트, 순위 순서, SRT 출력, JPG 비율 유지,
입력 파일 해시 불변, 기존 출력 경로 덮어쓰기 거부, 짧은 음악 처리 등을 검증했다.
`git diff --check` 통과.
최종 생성 패키지 `output/stage2-package-final`의 미리보기는 ffprobe 기준
1080×1920, H.264, 30/1fps, AAC, 영상·오디오·컨테이너 모두 3.000초다.
1초 프레임을 추출해 한글 자막과 이미지가 정상 렌더링됨을 눈으로 확인했다.
실제 앱 가져오기에 사용한 폴더는 초기 패키지 `output/stage2-package`이며,
후속 최종 패키지는 구성 JSON의 소수점 시간 표현을 프레임 기준으로 정리한 것이다.
